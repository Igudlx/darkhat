# /images

Drop your PNGs in here using these exact filenames. Recommended size: 128×128px (square), transparent background works best.

| Filename            | Used for                                      |
|----------------------|------------------------------------------------|
| `gamehub.png`         | GameHub desktop icon + window title icon       |
| `ai.png`               | AI desktop icon + window title icon            |
| `notes.png`            | Notes desktop icon + window title icon         |
| `coder.png`            | CodeR desktop icon + window title icon         |
| `folder.png`           | Folder icon — used for Extra, System, and Finished Projects |
| `file-text.png`        | Icon for note files inside System / Finished / Extra |
| `file-html.png`        | Icon for finished CodeR projects               |
| `file-css.png`         | Reserved — not wired to anything yet, add if you extend CodeR to show per-file icons |
| `file-js.png`          | Reserved — same as above |
| `favicon.png`          | Browser tab icon |

You don't need to add anything for a "missing logo" placeholder — if a PNG 404s, the site automatically falls back to a black square with a `?` (or `!` for Extra's link tiles), matching what you asked for. So it's safe to launch before you've made all the icons; things just won't look as good until you drop them in.
